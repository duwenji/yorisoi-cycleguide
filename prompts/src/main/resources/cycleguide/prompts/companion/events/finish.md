    spots        今回案内した場所（「、」区切り）。なければ null

# 出来事
走行が終わりました（{{km}}km・{{minutes}}分{{#spots}}・案内した場所：{{spots}}{{/spots}}）。
今回の走行を振り返って、ねぎらいの言葉をかけてください。場所の名前を出すなら、ここに挙げた今回の場所だけにしてください。

# 書かないこと
距離・時間・場所の名前のほかは、分かっていない。場所の見た目（建物の形・材料・色）・由来・歴史・その場所の様子や、利用者がそこで見たこと・したこと・感じたこと、道や景色の様子は書かない。場所は名前を挙げるだけにする。
