# サイクルガイド プライバシーポリシー

| 項目 | 内容 |
|---|---|
| アプリ | サイクルガイド（Android、`io.github.duwenji.yorisoi.cycleguide`） |
| 運営者 | duwenji |
| 問い合わせ先 | duwenji@gmail.com |
| 制定日 | 2026-10-25 |

サイクルガイド（以下「本アプリ」）は、自転車で走る人に、進む先の見どころや天気・日の入りなどを声で伝えるアプリです。本ポリシーは、本アプリが扱う情報と、その送り先を説明します。

## 1. 運営者が受け取る情報

本アプリには、アカウントの登録がなく、利用状況の解析（アナリティクス）、広告の SDK、クラッシュの報告の送信も入っていません。利用者の設定と走行の記録を、運営者が受け取ることはありません。

運営者が受け取るのは、利用者が設定で「運営の AI」を使うときに、AI に渡す内容を中継するためのものだけです（「2. 外部サービスへの送信」の「運営の AI の中継」）。中継は、案内と話しかけの内容を保存せず、ログにも書きません。残すのは、1 日に使える回数を数えるための記録（インストール ID から作った値・日付・回数・文章の長さ・応答時間・エラーの種類）だけで、7 日で消します。インストール ID そのものは保存しません。

また、周辺のスポットを探すときに、運営者が配るスポットのタイル（OpenStreetMap から作ったもの）を取ります（「2. 外部サービスへの送信」の「運営のスポットのタイルの配信」）。運営者に分かるのは、取られたタイルの名前（約 4km × 5km の範囲）だけで、配信はアクセスの記録を残しません。

利用者がスタジオ（場所に残る一言と、地域の提供者の掲載）を使うときは、運営者のスタジオのサーバーに、利用者が置いた一言と、聞いた・開いた・いいね・通報・ブロックを送ります（「6. スタジオ」）。

本アプリが外部と通信するのは、次の「2. 外部サービスへの送信」に書いたサービスとだけです。

## 2. 外部サービスへの送信

本アプリは、機能を提供するために、次のサービスと直接通信します。各サービスでの情報の扱いは、それぞれのサービスのプライバシーポリシーに従います。

| 送り先 | いつ | 送る情報 |
|---|---|---|
| 運営の AI の中継（運営者が Amazon Web Services の東京リージョンで動かすもの。設定で「運営の AI」を選んだときだけ） | 見どころの案内と話しかけを作るとき、その日に使える回数を調べるとき | 下の「AI サービス」と同じ内容と、インストール ID（本アプリが作るランダムな値。端末や利用者を特定する情報ではありません）。中継は、受け取った内容を Amazon Bedrock（日本の中で処理する生成 AI）に渡して答えを作ります |
| AI サービス（Anthropic・DeepSeek・OpenAI・Google のうち、利用者が設定で選んだもの、または利用者が指定した OpenAI 互換のサービス。設定で「自分の API キー」を選んだときだけ） | 見どころの案内と話しかけを作るとき | 見どころの名前・種類・距離・OpenStreetMap の情報（宗教・史跡の種類・Wikipedia の項目名など）、日時・天気・走り方、走った時間・距離、今回案内した場所の名前、最近話した内容。利用者自身の API キーを使います。**緯度経度と走った経路は送りません** |
| 運営のスポットのタイルの配信（運営者が Amazon Web Services の CloudFront で配るもの） | 進む先の見どころ・施設・信号の位置を探すとき。走っていないときに、よく通る道に沿って前もって取るとき（Wi-Fi などのときだけ） | 進む先の周りのタイルの名前（約 4km × 5km の範囲を表す 5 文字）。緯度経度は送りません |
| OpenStreetMap の Overpass API（公開サーバー。運営のスポットのタイルが取れないときだけ） | 進む先の見どころ・信号の位置を探すとき。走っていないときに、よく通る道に沿って前もって探すとき（Wi-Fi などのときだけ） | 現在地から少し先の範囲、またはよく通る道の上の点（緯度経度） |
| 運営のスタジオ（運営者が Amazon Web Services の東京リージョンで動かすもの。運営の AI の中継が使えるときだけ） | 走行中に近くの一言・掲載を取るとき（5 分おき）。一言を置くとき。走行の終わり。通報・ブロック・自分の一言の確認のとき | 取るとき: 周辺の区画の名前（約 1.2km × 0.6km の範囲を表す 6 文字）。置くとき: 一言の文字・区画の名前（約 150m の範囲を表す 7 文字）・近くの見どころの名前・期限。走行の終わり: 聞いた・開いた・いいねした一言と掲載の ID。どれも、運営の AI の中継の一時的な鍵を付けます。緯度経度と声は送りません |
| Open-Meteo | 天気・予報・日の入り時刻を調べるとき | 現在地の緯度経度 |
| 国土地理院の地図タイル | 走行中に止まって地図を表示するときと、走行の履歴の地図を表示するとき | 表示している範囲 |
| OpenStreetMap Foundation の地図タイル（利用者が設定で「OSM 標準」を選んだときだけ） | 走行中に止まって地図を表示するときと、走行の履歴の地図を表示するとき | 表示している範囲 |
| チャンネル・リストの発行元（開発者モードで利用者がリストを足したときだけ。既定ではなし） | リストと、選んだチャンネル・素材を取得するとき | 位置情報も利用者の情報も送りません。ただし、チャンネルが「基準」で素材を選ぶ場合は、取得する素材集から、走行中にいる大まかな地域（約 150km 四方）が発行元に分かりうるものです |

いずれの通信でも、利用者の名前・メールアドレス・端末の識別子は送りません（運営の AI の中継に送るインストール ID は、本アプリを入れ直すと変わる値です）。ただし、通信の性質上、各サービスには端末の IP アドレスが伝わります。

## 3. 位置情報

本アプリは、進む先の見どころと信号の位置を探す、止まったか走っているかを知る、走った距離を数える、天気を調べるために、端末の位置情報を使います。

- 「走り始める」を押してから「走行を終える」を押すまで、画面を閉じても位置を追い続けます（フォアグラウンドサービス。通知が出ている間だけです）
- 走行の外では、位置を使いません
- 位置の送り先は、上の「2. 外部サービスへの送信」のとおりです

## 4. 端末に保存する情報

次の情報は、端末の中（本アプリ専用の領域）にだけ保存します。

| 情報 | 内容 |
|---|---|
| 設定 | 走り方とその値、チャンネル、AI サービスの種類・モデル・1 日の上限など |
| API キー | AI サービスのキー。端末の外に出ない鍵（Android Keystore）で暗号化して保存します |
| インストール ID | 運営の AI を初めて使うときに作るランダムな値と、中継から受け取った一時的な鍵（24 時間で切れます） |
| スタジオ | 一言・掲載を聞くかどうか、同意した利用規約の版、聞いた一言と掲載の ID（同じものを繰り返さないため。8 日まで）、まだ送っていない聞いた・開いた・いいね、ブロックした一言の文字（ブロックの一覧で見分けるため）、掲載の音声のキャッシュ |
| 開発者モードの詳しい記録 | 開発者モードで始めた走行だけ。位置の推移・話しかけの判定と発言・AI に送った内容と答え・見どころの検索と天気の取得の結果。最新 30 件まで。開発者モードのときは利用者が選んだ場所に書き出せます |
| 走行の履歴 | 走行ごとの、始めた日時・距離・時間・走った道・話した見どころとその話・振り返り・通ったよく通る道（最新 500 件まで）。次の走行で同じ見どころを同じように話さないためにも使います。履歴の画面と、走っていないときの画面（いちばん新しい走行）に出します。設定で消せます |
| よく通る道 | 何度も走った道（自動で見つけたもの）と、利用者が履歴から作った道。名前・道の形・通った回数・最後に通った日。利用者が消した道の形も、もう一度見つけないために残します。設定で、自動で見つけるのを止められます。履歴を消すと、保存していない自動の道と消した道の形も消えます |
| 取得したもの | 見どころと信号の検索結果（検索した場所と、そこで見つかったもの。90 日まで）、足したチャンネル・リストとそのチャンネル・素材 |

これらは、クラウドのバックアップにも、機種変更のときの端末間の移行にも含めません。本アプリを削除すると、すべて消えます。

## 5. 第三者のチャンネル

本アプリが標準で使うのは、アプリに内蔵のチャンネルだけです。開発者モードで利用者がチャンネル・リストを足すと、第三者（チャンネル提供者・素材提供者）が作り、リストの運営が審査した自転車向けのチャンネルを使えます。チャンネル提供者・素材提供者に、利用者の情報は送られません。

チャンネル・リストの画面の「問題を知らせる」は、メールのアプリで下書きを開くだけです。宛先は、そのチャンネルを載せたリストの運営です。下書きには、チャンネルの名前と版、アプリの版が入ります。位置は入りません。送るかどうかは利用者が決めます。

## 6. スタジオ

スタジオは、利用者が場所に残した短い一言と、運営が承認した地域の提供者（チャンネル提供者・素材提供者）の掲載を、近くを走る人に読み上げる機能です。設定で「一言を聞く」「お知らせを聞く」をオンにしたときだけ読み上げます。一言を置く・いいね・通報・ブロックは、止まっているときだけできます。

- **一言を置く**: 利用者が話した一言は、端末の中で文字にします。声そのものは送りません。初めて置く前に、一言の利用規約への同意を求めます
- **サーバーが残すもの**: 一言（期限まで）、置いた人を表す値（インストール ID から作った値。ブロックのため、一言の期限から 7 日まで）、一言・掲載ごと・日ごとの聞いた数・開いた数といいねの合計、いいねと通報の重複を防ぐ組（通報は 30 日）、ブロックの組（ブロックした人とされた人を表す値。解くまで、最長 1 年）。だれがどの一言・掲載を聞いたか、取った区画、緯度経度は残しません。インストール ID そのものも残しません
- **運営の確認**: 置かれた一言は、運営の AI（Amazon Bedrock）と決まった型（電話番号など）で自動で確かめ、当たったものは届けません。通報された一言・掲載は運営が見て、消すことがあります。消した一言を置いた端末は、一言を置けないように締め出すことがあります
- **ほかの人に見えるもの**: 一言の文字・近くの見どころの名前・区画だけです。置いた人を表す値は、ほかの端末には送りません。置いた人には、聞いた数などのおおよその数（3 未満は出さない）だけが見えます
- 期限が来た一言と掲載は、2 日以内に消えます。自分の一言は、設定の「スタジオ」から期限の前に消せます

## 7. 子ども

本アプリは、子どもを対象としたものではありません。
