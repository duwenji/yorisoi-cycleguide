# Play Console の申告

Google Play Console に入れる答え。入れ方（画面の場所、データ セーフティのページの進め方、審査への出し方）は SanpoGuide の [Play Console の申告](https://github.com/duwenji/yorisoi-sanpoguide/blob/main/docs/play-console.md#手順)と同じ。API（`tools/play.mjs`）で送れるのは、AAB・ストアの説明文とスクリーンショット・連絡先・データ セーフティ・審査への送信で、しくみと準備は SanpoGuide の [play-api.md](https://github.com/duwenji/yorisoi-sanpoguide/blob/main/docs/play-api.md) のとおり（鍵は `~/.yorisoi-cycleguide/play-service-account.json`）。公開の流れと受け持ちは [release.md](release.md)。

## アプリの基本

| 項目 | 答え |
|---|---|
| パッケージ名 | `io.github.duwenji.yorisoi.cycleguide` |
| 署名 | Play App Signing。`release.jks` をアップロード鍵にする（写しは `~/.yorisoi-cycleguide/`） |
| プライバシーポリシー | https://duwenji.github.io/yorisoi-cycleguide/privacy-policy （GitHub Pages、main の `/docs`） |
| 広告 | 含まない。マニフェストに `com.google.android.gms.permission.AD_ID` はない（Google のライブラリは play-services-location だけ） |
| 公開する国・地域 | 日本だけ |
| 価格 | 有料（アプリの作成のときに選んだ）。金額は公開する前に [アプリの価格設定] で決める。自動保護はオン（Play 以外から入れたものに、Play から入れるよう促す確認が入る） |
| アプリのアクセス権 | 制限なし（ログインなし）。審査用の説明: 「AI の案内と話しかけは、設定なしで運営の AI を使える（1 日の回数に上限がある）。設定で自分の API キーに切り替えることもできる。走り始めるには位置情報の許可が要る」 |
| 対象年齢 | 18 歳以上（子どもを対象としない） |
| カテゴリ | アプリの「旅行＆地域情報」。タグは Travel guide・Travel & local・Maps & navigation |
| 連絡先の詳細 | ウェブサイトは https://github.com/duwenji/yorisoi-cycleguide 。メールアドレスは必須で公開される（この文書には書かない）。電話番号は空欄 |
| ニュースアプリ・政府のアプリ・金融・健康 | いいえ |
| コンテンツのレーティング | 暴力・性的・薬物・賭博・ユーザー同士の交流・位置の共有（ほかのユーザーへ）はすべていいえ。「ユーザーが生成したコンテンツ」はいいえ、生成 AI の利用ははい |

## ストアの掲載情報

言語は日本語だけ。AI アセットの申告は「使った」（アイコン・フィーチャー グラフィック・説明文は生成 AI で作った。スクリーンショットはアプリの実際の画面）。

| 項目 | 入れるもの |
|---|---|
| アプリ名 | `サイクルガイド` |
| 簡単な説明 | [下の文](#簡単な説明) |
| 詳しい説明 | [下の文](#詳しい説明) |
| アプリのアイコン | [`store/icon-512.png`](../store/icon-512.png) |
| フィーチャー グラフィック | [`store/feature-1024x500.png`](../store/feature-1024x500.png) |
| スマートフォンのスクリーンショット | [`store/screenshots/`](../store/screenshots/) を番号の順に。画面で入れる（`tools/play.mjs --screenshots` は、このアプリでは Play が内部エラーを返して受け付けなかった） |

アイコンとフィーチャー グラフィックは [`store/src/`](../store/src/) の SVG から `sh store/src/build.sh` で作る。

説明文には、星・絵文字・誇張を使わない。運営の AI には 1 日の回数の上限があること、自分の API キーの利用料は各サービスから請求されること、走っている間はスマートフォンを操作しないことは必ず書く。`tools/play.mjs` の `--listing` は、下の 2 つの見出しのすぐ下の `text` のコードブロックを送る。

#### 簡単な説明

```text
自転車で走る先の見どころや、天気・日の入りを声で知らせる。画面を見ずに使えます
```

#### 詳しい説明

```text
サイクルガイドは、自転車で走る人のそばで、進む先の見どころや天気の変化を声で伝えるアプリです。走っている間は画面に何も出さず、操作も求めません。

■ 進む先の見どころ
進む方向の少し先にある寺社・史跡・公園・博物館などを、着く前に短く案内します。間に合わなかった見どころは、次に止まったときに話します。

■ 止まったときの話と地図
信号待ちでは少し長めに、休憩ではもう少しゆっくり話します。止まっている間は、見どころと走ってきた道を地図に出します。走り終えたあとは、前回の走行の道と話した見どころを地図で見返せます。信号の近くや速く走っているときは、天気と日の入りの知らせのほかは話しません。

■ 安全のための知らせ
1 時間以内の雨や雷雨、日の入りが近いこと（ライトの点灯）を知らせます。

■ 走り方
街中をゆっくり走る「ポタリング」と、長い距離を走る「ロングライド」から選べます。探す距離や話の長さなどを細かく変えることもできます。

■ チャンネル
標準・歴史をたどる・しずかに から、語り手と話題を選べます。

■ 使うときに必要なもの
・位置情報の許可
・AI の案内と話しかけは、設定なしで「運営の AI」を使えます。1 日に使える回数に上限があり、使い切った日は決まった文で案内します。
・生成AI サービス（Anthropic・OpenAI・Google・DeepSeek、または OpenAI 互換のサービス）の API キーを持っていれば、設定の画面で切り替えて使えます。API キーの利用料は、各サービスから利用者に請求されます。

■ 安全について
自転車を運転しながらスマートフォンを手に持って使うことや、画面を見続けることは、道路交通法で禁止されています。操作は止まってからにしてください。周りの音が聞こえない状態でのイヤホンの使用も、多くの都道府県の規則で禁止されています。周りの音が聞こえる状態で使ってください。

■ プライバシー
アカウントの登録、利用状況の解析、広告はありません。API キーは端末の中だけに保存します。運営の AI を使うときは、案内と話しかけに使う情報が運営の中継を通りますが、中継は内容を保存しません。位置は、見どころや天気を調べるために外部のサービスへ送ります。AI には緯度経度を送りません。詳しくはプライバシーポリシーをご覧ください。

地図データ © OpenStreetMap の貢献者
```

#### スクリーンショット

1. `01-main.png`: 走り始める前のメインの画面（走り方とチャンネル）
2. `02-spoken.png`: 止まったときに、AI が話した見どころの案内（作者つき）と、見どころ・走った道を出した地図
3. `03-settings.png`: 走り方の設定（ポタリングとロングライド、値の調整）
4. `04-safety.png`: 初めて走る前の注意

撮り方は SanpoGuide と同じ（1080×2160、時刻帯 `Asia/Tokyo`、デモ モードのステータスバー、観光地の位置、24 ビットの PNG）。走っている間の画面は「走行中」だけなので入れない。

## データ セーフティ

答えは SanpoGuide と同じ種類で、[play-data-safety.csv](play-data-safety.csv)（Play Console の書き出しの形式、改行は CRLF）。

| データの種類 | 収集 | 共有 | 一時的な処理 | 任意か | 目的 |
|---|---|---|---|---|---|
| 位置情報 > おおよその位置情報 | はい | いいえ | はい | 必須 | アプリの機能 |
| 位置情報 > 正確な位置情報 | はい | いいえ | はい | 必須 | アプリの機能 |
| アプリのアクティビティ > その他のユーザー作成コンテンツ（走行の状況のまとめを AI へ） | はい | いいえ | はい | 任意（AI を使うときだけ） | アプリの機能 |
| デバイスまたはその他の ID（運営の AI の中継へのインストール ID） | はい | いいえ | いいえ | 任意（運営の AI を使うときだけ） | アプリの機能、不正行為の防止・セキュリティ |

- 位置は Overpass（見どころ・信号）と Open-Meteo（天気）に送る。地図を出すときは、表示している範囲が国土地理院の地図タイル（設定で「OSM 標準」を選んだときは OpenStreetMap Foundation の地図タイル）に伝わる。AI には送らない。前回の走行の道は端末の中にだけ残す（送らないので、データ セーフティの「収集」には当たらない）
- 送るデータはすべて HTTPS。アカウントはない。データの削除は「いいえ（ただしユーザーデータは 90 日以内に自動で削除）」
- 申告しないもの: 設定・API キー・開発者モードの記録は端末の外に出ない。名前・メールアドレス・端末の ID・診断情報は扱わない

## フォアグラウンドサービスの申告

| 項目 | 答え |
|---|---|
| 種類 | 位置情報（`foregroundServiceType="location"`、`FOREGROUND_SERVICE_LOCATION`） |
| バックグラウンドの位置情報の権限 | 求めない（`ACCESS_BACKGROUND_LOCATION` なし。利用者が画面で「走り始める」を押したときに始める） |
| 説明 | 利用者が「走り始める」を押してから「走行を終える」を押すまで、画面を閉じても現在地を追い、進む先の見どころの案内、止まったかどうかの判定、天気・日の入りの知らせをする。走行中は通知を出し続け、止まっているときは通知の「終了」からも終えられる |
| 利用者への影響 | 位置を追うのをやめると、画面を閉じている間の案内と安全の知らせが途切れる |
| 動画 | [`store/videos/foreground-service-demo.mp4`](../store/videos/foreground-service-demo.mp4)。「走り始める」→ 通知が出る → 走って画面が「走行中」になる → 見どころを話す → 止まって通知の「終了」で終える。Play Console には jsDelivr のコミット固定の URL https://cdn.jsdelivr.net/gh/duwenji/yorisoi-cycleguide@1f89878/store/videos/foreground-service-demo.mp4 を入れる（`video/mp4` で返る。`@` の後ろは動画を入れたコミット。撮り直したら URL も直す） |
