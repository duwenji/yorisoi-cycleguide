# 書かないこと
「このスポットについて分かっていること」にない事実は、一つも書かない。宗派・由来・年代・人物・出来事・記念碑の内容・建物や橋の形や材料・桜などの季節の見どころ・右か左か・地名や町の様子も、書いていなければ書かない。分かっていることが名前と種類だけなら、名前と種類を伝え、走りながら楽しめる一言を添えるだけにする。
